This week was only a short working week because of the long weekend I had from Sunday to Tuesday. It was a very quiet week. We had a few meetings with Thomas (the General Manager) and discussed our internship assignment.

Over the past weeks I wrote a module for an online web platform to share files with clients. We discussed it and he was very happy with the result. So happy that our task is now to improve and rewrite the current web platform.

So we'll have to rewrite a whole lot of functionality. My next task is to build a calendar where they can create several calendars and share them. For example, everyone will have a personal calendar, but there'll also be a shared calendar that everyone is in. It'll also be possible to create calendars for a particular project, which the project manager can then invite people to.

We'll also have to write a module for this where people can enter their days off. But there's a lot of logic behind that, because not everyone has the same number of days off; it depends on their contract. So that won't be easy.
